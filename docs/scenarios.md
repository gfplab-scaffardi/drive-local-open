# 失敗シナリオ（S1–S14）

計画どおりの安定動作仕様です。回帰テストは `tests/scenarios/` を参照。

| ID | 内容 | 実装 |
|----|------|------|
| S1 | Drive/Docs 以外 | 対象外メッセージ、何も開かない |
| S2 | Drive 未導入 | 公式 DL リンク付きメッセージ |
| S3 | 複数アカウント | 最初の一致を採用し、stderr note |
| S4 | 未同期 | 存在する親へフォールバック（`--no-fallback-parent` で無効化可） |
| S5 | 共有／ショートカット | `.shortcut-targets-by-id` + 共有ドライブ探索 |
| S6 | ファイル/Docs | 親フォルダを開く |
| S7 | my-drive | マイドライブを開く |
| S8 | tombstone | 削除済みメッセージ |
| S9 | DB 障害 | read-only URI、再起動案内 |
| S10 | NFC/NFD | パス正規化バリアント |
| S11 | 巨大ツリー | xattr walk はタイムアウト付き最終手段 |
| S12 | Chrome URL 取得不可 | ブックマークレットの URL 引き渡しへ |
| S13 | プロトコル初回ブロック | 案内ページの許可手順 |
| S14 | オフライン | ローカル解決のみ（ネット不要） |
